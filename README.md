# UNITY — Father of Lights

First mobile-first Genesis pixel for the UNITY project.

## Current scope

This repository is intended to host the first runnable version of the UNITY Genesis pixel: a mobile web interface, a persistent agent identity, and a chat backend.

## Important

Do not commit API keys or secrets. Configure `OPENAI_API_KEY` only as a private environment variable in the deployment platform. A published repository is not itself a running service; deployment and runtime configuration are required.

The application source files must be added before deployment. See the project archive shared in the ChatGPT conversation for the initial implementation.
